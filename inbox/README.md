# À intégrer

Dépose ici les fichiers HTML bruts, sous n'importe quel nom, puis demande
l'intégration. Claude s'occupe du reste : renommage selon la convention,
métadonnées, liens, index, tests, commit, push.

Ce dossier est une boîte aux lettres, pas un rangement : il a vocation à être
vide. Son contenu n'est ni versionné (`.gitignore`) ni publié (`.cfignore`) —
un brouillon posé ici n'apparaît jamais en ligne.

La procédure d'intégration est décrite dans `CLAUDE.md`, à la racine.
