Périmètre : Signal : espace de recherche monotone ; invariant sur [lo, hi] ; variant hi − lo ; bornes inclusives/exclusives ; « premier vrai » ; recherche sur la réponse. Figure : `trace`.
Format coding : signal dans l'énoncé → pattern → squelette de l'invariant/variant (TAP) → `trace` animée sur un exemple de 8 à 12 cases → complexité (composition) → pièges Python → cartes « signal → pattern » liées. Jamais la solution complète en clair : le squelette et la trace, le code est à lui.
