## Question de la chaîne
Que cherche la PCA, pourquoi c'est un problème de valeurs propres, et pourquoi elle donne un résultat faux sans lever d'erreur si on ne centre pas, si on ne standardise pas, ou si on l'ajuste sur le test ?

## Prérequis
- p04-03 : spectral (symétrique ⇒ QΛQᵀ), SVD, XᵀX = VΣ²Vᵀ.
- p00-02 : variance, covariance ; Var(aᵀx) = aᵀCa.

## Hypothèses posées
- H1 : la structure intéressante est **linéaire** et se lit dans la **variance** — deux hypothèses fortes.
- H2 : X est n×p, une ligne par observation ; C = XcᵀXc/(n − 1) sur les données **centrées**.

## Exemple fil rouge
Trois points (1, 2), (2, 3), (3, 4). Centrés : (−1, −1), (0, 0), (1, 1). C = [[1, 1], [1, 1]] : valeurs propres 2 et 0 ; PC1 = (1, 1)/√2 porte 100 % de la variance ; PC2 = (1, −1)/√2 en porte 0. Les trois points sont sur une droite : une seule dimension suffit.
**Sans centrer** : XᵀX/2 = [[7, 10], [10, 14,5]] : valeurs propres 21,4 et 0,07, première direction (0,57 ; 0,82) — elle pointe vers le centre du nuage, pas le long de sa variance.
**Sans standardiser** : quatre points avec x₁ ∈ {1, 2, 3, 4} et x₂ ∈ {100, 300, 200, 400} : PC1 = (0,008 ; 1,000), λ₁ = 16 668 contre 0,6 : la PCA ne voit que la feature en centaines. Standardisées : PC1 = (0,71 ; 0,71), λ = (1,8 ; 0,2).
Covariance C = [[1, 1], [1, 4]] (p04-03) : PC1 = (0,29 ; 0,96) avec 4,30/5 = 86 % de la variance.

## Pas de la chaîne
1. **Le décor.** p features corrélées ; on veut k < p directions qui gardent l'essentiel. « L'essentiel » = la variance (H1).
2. **La variance projetée est une forme quadratique** [tronc]. Projeter x sur une direction unitaire a donne aᵀx ; sa variance sur le nuage centré est aᵀCa. Au tableau : « La projection est linéaire, donc sa variance est aᵀCa, donc chercher la direction de variance maximale c'est maximiser une forme quadratique sur la sphère unité. »
3. **Le maximum est un vecteur propre** [tronc]. Par le spectral, aᵀCa = Σλᵢ(coordonnée i)² sur la base propre, avec Σ(coordonnée)² = 1 : c'est maximal en mettant tout sur λ_max. PC1 = direction propre dominante, variance portée = λ₁. PC2 = la suivante, orthogonale, etc. Au tableau : « Dans la base propre la forme quadratique est une moyenne pondérée des λ, donc le maximum sous norme unité est atteint sur la plus grande valeur propre, donc la première composante est le vecteur propre dominant. »
4. **Ce que disent les λ.** λᵢ/Σλ = part de variance expliquée ; Σλ = trace C = variance totale. Choisir k : coude, ou seuil (90 %). Reconstruction : projeter sur les k premières puis revenir ; l'erreur est Σ_{i>k} λᵢ (SVD tronquée de p04-03).
5. **Piège 1 : centrer** [casse]. Sans centrer, XᵀX mesure les moments autour de 0, pas de la moyenne ; la première direction pointe vers le centre du nuage. Résultat faux, aucune erreur. Au tableau : « La covariance est définie autour de la moyenne, donc sans centrer on diagonalise autre chose, donc la première direction est le centre du nuage et non sa dispersion. »
6. **Piège 2 : les unités** [casse]. La variance porte les unités au carré ; une feature en centaines domine une feature en unités sans être plus informative. Standardiser (diviser par l'écart-type) quand les unités diffèrent ; ne pas standardiser quand elles sont comparables et que les écarts de variance sont l'information (pixels). C'est un choix, pas un réglage par défaut.
7. **Piège 3 : ajuster sur le train seulement.** Moyenne, écart-type et directions viennent du train ; on **transforme** le test avec eux. Ajuster sur tout = fuite (p06-02). `fit` sur train, `transform` sur test.
8. **PCA = SVD des données centrées.** Xc = UΣVᵀ ⇒ C = VΣ²Vᵀ/(n − 1) : composantes = colonnes de V, λᵢ = σᵢ²/(n − 1), scores = UΣ. On calcule la SVD de Xc, pas les valeurs propres de C (p04-03, pas 7).
9. **Où ça casse** [casse].

## Où ça casse
- **Structure non linéaire** : un cercle, un S — la PCA ne voit que des ellipses ; kernel PCA, UMAP (nommer).
- **Variance ≠ information** : la direction de plus grande variance peut être du bruit (capteur) ou une variable parasite ; pour prédire y, la PCA ignore y (PLS, nommer).
- **Outliers** : la covariance est quadratique, un point aberrant tire PC1 vers lui.
- **Interprétation** : les composantes sont des mélanges de toutes les features ; « PC1 = taille » est une lecture, pas un fait.

## Résumé
1. PCA = directions de variance maximale ; Var(aᵀx) = aᵀCa.
2. Maximiser aᵀCa sur la sphère ⇒ vecteur propre dominant ; λᵢ = variance portée, λᵢ/trace = part expliquée.
3. Centrer, sinon la direction pointe vers le centre du nuage.
4. Standardiser si les unités diffèrent ; sinon la variance fabrique la composante.
5. fit sur train, transform sur test.
6. Calcul : SVD des données centrées ; composantes = V, λ = σ²/(n − 1).

**Phrase d'entretien** : « La PCA maximise la variance projetée, qui est une forme quadratique de la covariance ; son maximum sur la sphère unité est le vecteur propre dominant, et les suivants sont orthogonaux. Elle est fausse sans erreur si on ne centre pas, parce que la covariance est définie autour de la moyenne ; si on ne standardise pas des unités hétérogènes, parce que la variance porte les unités au carré ; et si on l'ajuste sur le test, parce que c'est une fuite. On la calcule par SVD des données centrées. »

## Chaîne verbalisée
1. Que maximise la PCA, et sous quelle forme ? → aᵀCa sur ‖a‖ = 1.
2. Pourquoi la solution est un vecteur propre ? → Base propre : Σλᵢ(coord)² maximal sur λ_max.
3. Que se passe-t-il sans centrer ? → On diagonalise XᵀX : la direction pointe vers le centre du nuage.
4. Quand standardiser, quand non ? → Unités hétérogènes : oui ; unités comparables où la variance est l'info : non.
5. PCA et SVD : quel lien ? → Xc = UΣVᵀ ; composantes V, λ = σ²/(n − 1) ; ne pas former C.
6. Que fait-on du test ? → transform avec moyenne, écart-type et V du train.

## Exclusions
Pas de kernel PCA ni UMAP au-delà du nom, pas de PCA probabiliste, pas de dérivation lagrangienne du maximum (le spectral suffit).

## Questions pour la revue

polynôme caractéristique, vecteurs propres à la main ; contrôles Σλ = trace, Πλ = det,
orthonormalité, parts sommant à 1). **Aucun n'est faux** : 2 / 0, 21,43 / 0,070 et
(0,57 ; 0,82), 16 667,7 / 0,600 et (0,008 ; 1,000), 1,8 / 0,2 et (0,71 ; 0,71),
4,303 / 0,697 et (0,29 ; 0,96) avec 86,1 %. Restent quatre points à trancher.

1. **Appariement du nuage « sans standardiser ».** Le spec donne x₁ ∈ {1, 2, 3, 4} et
   x₂ ∈ {100, 300, 200, 400} sans dire l'appariement. La sheet lit (1, 100), (2, 300),
   (3, 200), (4, 400) : c'est le seul appariement qui redonne exactement les chiffres du
