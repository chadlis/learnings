Périmètre : Le rituel : invariant inductif avec conteneur nommé et tranche exacte ; variant entier ≥ 0 strictement décroissant ; conclusion qui ouvre par « donc » ; hors boucle « + », dans la boucle « × » ; espace min(n,|Σ|). Cassé pour Salah : conclusion sur le déroulement au lieu du résultat ; espace donné en valeur d'exécution.
Format coding : signal dans l'énoncé → pattern → squelette de l'invariant/variant (TAP) → `trace` animée sur un exemple de 8 à 12 cases → complexité (composition) → pièges Python → cartes « signal → pattern » liées. Jamais la solution complète en clair : le squelette et la trace, le code est à lui.
