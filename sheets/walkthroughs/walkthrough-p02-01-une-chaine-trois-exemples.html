0 · Le décor Trois observations, deux features, la seconde vaut exactement deux fois la première. x1 = (1, 2, 3)  ·  x2 = (2, 4, 6)  ·  y = (1, 2, 3) Modèle linéaire sans intercept : f(x; β) = β1x1 + β2x2. On cherche β = (β1, β2).

Pourquoi cet exemple : petit au point de tout calculer à la main, et colinéaire — il fera casser la chaîne au pas 8, exactement là où il faut.

1
Hypothèse sur le bruitsupposé C'est le seul endroit où l'on suppose une loi sur les données ; l'autre hypothèse, l'indépendance, n'autorise que le produit du pas 3. Tout le reste est du calcul.
yi = f(xi; β) + εi,   εi ~ N(0, σ²), indépendants Le bruit est gaussien, de même variance partout, et chaque observation tire le sien. Écriture équivalente, la seule qui survivra à l'exemple 2 : yi | xi ~ N(f(xi; β), σ²) — la gaussienne est une famille de position, f ne fait que la translater, donc le bruit se sépare.
2
Densité d'une observation On modélise y sachant x, jamais x. On injecte εi = yi − f(xi; β) dans la densité du bruit.
p(yi | xi; β) = (1/(σ√(2π))) · exp( −(yi − β1x1i − β2x2i)² / (2σ²) ) Le 2 sous σ² fait partie de la gaussienne. Il manquait en séance.
3
Produit Observations indépendantes ⇒ la probabilité de les voir toutes est le produit. C'est la vraisemblance L(β) : fonction de β, données fixées.
L(β) = Πi=13 p(yi | xi; β) Où ça casse : séries temporelles, mesures répétées sur un même sujet — le produit ment.
4
Log log(ab) = log a + log b : le produit devient une somme. L'argmax ne change pas, le log est croissant.
ℓ(β) = −3·log(σ√(2π)) − (1/(2σ²)) · Σi (yi − β1x1i − β2x2i)² Le 3 devant la constante : une par observation. Il manquait en séance.
5
Négatif Maximiser ℓ = minimiser −ℓ. C'est le signe qui fabrique une loss à partir d'une vraisemblance.
NLL(β) = 3·log(σ√(2π)) + RSS(β) / (2σ²), avec RSS(β) = Σi (yi − β1x1i − β2x2i)²
6
Jeter L'argmin ignore une constante additive et un facteur positif. On jette ce qui ne dépend pas de β. Ce qui reste porte un nom.
argminβ NLL(β) = argminβ RSS(β) Jeté : 3·log(σ√(2π)) (additif) et 1/(2σ²) (multiplicatif positif).

Sur l'exemple, comme x2 = 2x1 : f(xi) = (β1 + 2β2)·x1i. Pose s = β1 + 2β2. Alors RSS = Σ(yi − s·x1i)² = 14 − 28s + 14s² = 14(1 − s)². Les données ne voient que s.

XᵀX = [[14, 28], [28, 56]],   valeurs propres 0 et 70,   Xᵀy = (14, 28)

D'où sortent 0 et 70. Pour une 2×2, det(A − μI) = 0 ⇔ μ² − tr(A)·μ + det(A) = 0. tr = 14 + 56 = 70 ; det = 14·56 − 28² = 784 − 784 = 0 ; donc μ(μ − 70) = 0 : μ = 0 et μ = 70. Contrôles : somme 70 = trace, produit 0 = déterminant. Vecteurs propres : XᵀX(2, −1) = (28 − 28 ; 56 − 56) = (0, 0), donc (2, −1) pour 0 ; XᵀX(1, 2) = (14 + 56 ; 28 + 112) = (70, 140) = 70·(1, 2), donc (1, 2) pour 70. Non inversible parce que μ = 0 : v = (2, −1) est envoyé sur 0.

Rang 1 sur 2. Non inversible. Le RSS est minimal (nul) pour tout β tel que s = 1 : une droite entière de solutions.

−log prior → pénalité Même geste que les pas 4–6, appliqué à β au lieu de y. Le MAP minimise NLL + (−log p(β)).
−log p(β) = const + ‖β‖² / (2τ²) argminβ [ RSS/(2σ²) + ‖β‖²/(2τ²) ] = argminβ [ RSS + λ‖β‖² ],   λ = σ²/τ² C'est Ridge. Et λ a un sens : bruit fort ou prior étroit ⇒ λ grand, on croit le prior.
11
Ce que la pénalité fournit Le RSS est constant sur la droite s = 1. λ‖β‖² ne l'est pas. Lui seul décide.
Sur la droite, (β1, β2) = (1 + 2t, −t) : ‖β‖² = (1 + 2t)² + t² = 1 + 4t + 4t² + t² = 5t² + 4t + 1, parabole ; le minimum de at² + bt + c est en t = −b/(2a) = −4/10 = −0,4 → β = (1 − 0,8 ; 0,4) = (0,2 ; 0,4), un minimum. Côté matrice : (XᵀX + λI)v = (μ + λ)v. Les valeurs propres deviennent λ et 70 + λ. Toutes > 0 ⇒ inversible. Rien n'est annulé, tout est translaté.

Ridge ne combat pas l'overfitting, il rend unique une solution qui ne l'était pas. L'amélioration en test est une conséquence (biais-variance), pas le mécanisme.

β̂ pénalisé, chiffré La forme fermée existe à nouveau.
β̂ = (XᵀX + λI)⁻¹ Xᵀy Inverse d'une 2×2 : [[a, b], [c, d]]⁻¹ = (1/det)·[[d, −b], [−c, a]]. λ = 1 : XᵀX + I = [[15, 28], [28, 57]], det = 15·57 − 28² = 855 − 784 = 71. Donc β̂ = (1/71)·[[57, −28], [−28, 15]]·(14, 28) : β̂1 = (57·14 − 28·28)/71 = (798 − 784)/71 = 14/71 = 0,197 ; β̂2 = (−28·14 + 15·28)/71 = (420 − 392)/71 = 28/71 = 0,394.

En général, sans inverser. Xᵀy = 14·(1, 2) est vecteur propre de XᵀX pour 70 (pas 8), donc de XᵀX + λI pour 70 + λ, donc (XᵀX + λI)⁻¹·14(1, 2) = 14/(70 + λ)·(1, 2) = (1/5)·(70/(70 + λ))·(1, 2). Pose r = 70/(70 + λ) : β̂ = (r/5)·(1, 2). Ridge rétrécit le long de la direction propre, il ne tourne pas. Contrôle λ = 1 : r = 70/71 = 0,986, (0,197 ; 0,394). λ = 10 → r = 0,875, (0,175 ; 0,35). Le point bleu de la figure, tiré vers l'origine quand λ monte.

0 · Le décor Quatre points sur une droite, une cible binaire, parfaitement séparables. x = (−2, −1, 1, 2)  ·  y = (0, 0, 1, 1) Modèle : pi = σ(β·xi), σ la sigmoïde. On cherche un seul nombre, β.

Pourquoi cet exemple : la chaîne est identique à l'exemple 1 jusqu'au pas 7, puis casse autrement au pas 8 — pas « trop de solutions », mais « aucune ».

1
Hypothèse sur le bruitsupposé Pour une cible 0/1, il n'y a pas de ε à séparer : la loi de y sachant x est une Bernoulli dont f règle la probabilité, et la dispersion p(1 − p) en découle. C'est le cas général ; « prédiction + bruit » à l'exemple 1 était le cas particulier.
yi ~ Bernoulli(pi),   pi = σ(β·xi), indépendants yi − pi vaut −pi ou 1 − pi : un « bruit » dont la loi dépend de xi, rien à supposer à part.
2
Densité d'une observation Une seule formule pour y = 0 et y = 1. C'est l'astuce d'écriture qui rend tout mécanique.
p(yi | xi; β) = piyi (1 − pi)1−yi Vaut pi si yi = 1, 1 − pi si yi = 0.

Forme en logits, d'où elle sort. Deux identités : −log σ(t) = log(1 + e−t) et 1 − σ(t) = σ(−t). Pose zi = βxi. Terme y = 1 : −log pi = log(1 + e−zi). Terme y = 0 : −log(1 − pi) = −log σ(−zi) = log(1 + ezi) = zi + log(1 + e−zi). D'où NLL = Σi [(1 − yi)zi + log(1 + e−zi)]. Sur l'exemple : x = 1, y = 1 → log(1 + e−β) ; x = −1, y = 0 → −log(1 − σ(−β)) = −log σ(β) = log(1 + e−β) ; la paire ±1 donne 2·log(1 + e−β), la paire ±2 de même 2·log(1 + e−2β) : NLL(β) = 2·log(1 + e−β) + 2·log(1 + e−2β). C'est cette forme que calcule BCEWithLogitsLoss (p08-02).

si on avait pris la MSE Σ(yi − pi)² : (i) bornée par 1 par exemple — vrai, mais c'est un argument de valeur, pas le mécanisme ; (ii) le mécanisme : gradient 2(p − y)·p(1 − p), écrasé là où l'erreur est maximale, contre p − y pour la log-loss ; (iii) non convexe en β, là où la log-loss est convexe en z et z affine en β.

0 · Le décor Exactement les données de l'exemple 1. Une seule chose change : le pas 1. x1 = (1, 2, 3)  ·  x2 = (2, 4, 6)  ·  y = (1, 2, 3)

Pourquoi cet exemple : voir qu'en changeant uniquement l'hypothèse de bruit, toute la loss change, et qu'en changeant uniquement le prior, toute la pénalité change — et pas au même endroit.

Et ce n'est pas la même cible. Le minimiseur de la MSE est la moyenne conditionnelle ; celui de la MAE est la médiane conditionnelle. Pas « la même quantité estimée plus prudemment » : une autre quantité. Sur une distribution asymétrique (revenus, durées), elles ne coïncident pas, et la question « laquelle veux-tu prédire ? » se pose avant toute considération de robustesse. Quand supposer Laplace plutôt que gaussien ?

Le mécanisme, en un chiffre. Un résidu de 10 contre un résidu de 1 : la gaussienne le paie 100 fois plus cher, Laplace 10 fois. Sous MSE, l'influence d'un point n'est pas bornée — un seul aberrant déplace la solution arbitrairement loin. Sous MAE, elle l'est. On suppose Laplace quand on croit que de gros écarts arrivent normalement, pas exceptionnellement.

revenus, durées, temps de réponsela cible elle-même a des queues lourdes ; la gaussienne est démentie par les données

Compromis : Huber, quadratique près de zéro, linéaire au-delà d'un seuil δ (influence bornée, gradient qui s'éteint). Le prix de la MAE si le bruit est réellement gaussien : une efficacité moindre, variance de la médiane ≈ 1,57 fois celle de la moyenne.

ce qu'il faut savoir dire Personne ne dit « je suppose un bruit de Laplace » : on choisit la MAE parce qu'elle est robuste, et l'hypothèse est reconstituée après coup. Savoir faire le trajet dans ce sens — de la loss vers l'hypothèse qu'elle implique — permet de répondre « la MAE suppose des queues exponentielles et estime la médiane » plutôt que « la MAE est plus robuste ».

0 · Le décor Une seule observation, trois classes nommées : chat, chien, oiseau ↔ k = 1, 2, 3. z = (2, 0, −1)  ·  vraie classe chat, c = 1, one-hot y = (1, 0, 0) Modèle : un logit par classe, zk = wk · x, donc z = Wx avec W la matrice des wk. L'énoncé donne z directement, comme si W et x avaient été appliqués ; ce qu'on cherche est Ŵ. Notations : i = observation (une seule ici, on omet l'indice), k = classe, j = indice muet de sommation ; pk = probabilité de la classe k ; étiquette c et one-hot yk = 1[c = k]. Log naturel, ln, partout.

Pourquoi cet exemple : c'est l'exemple 2 avec K = 3 au lieu de 2. La chaîne tombe sur la cross-entropy de CrossEntropyLoss et s'arrête au pas 7 ; les pas 8 à 12 sont ceux de l'exemple 2.

1
Hypothèse sur le bruitsupposé y prend K = 3 valeurs, donc la loi est la catégorielle (multinoulli) — le mot se nomme, c'est du vocabulaire. Paramètres (p1, p2, p3) dans le simplexe : pk ≥ 0, Σk pk = 1, donc K − 1 = 2 paramètres libres (Bernoulli : 2 valeurs, 1 paramètre).
y ~ Catégorielle(p),   p = softmax(z) Qui fabrique les p : la softmax joue le rôle de σ. pk = ezk / Σj ezj : strictement positive (une exponentielle), donc log pk toujours défini ; somme Σk ezk / Σj ezj = 1.

piège softmax ≠ cross-entropy : la softmax transforme les logits en probabilités (rôle de σ, pas 1) ; la cross-entropy est la loss obtenue au pas 7.

« La loss est la trace du bruit ; la pénalité est la trace du prior. La vraisemblance seule ne détermine pas toujours de solution — trop, ou aucune — et la pénalité fournit ce qui manque. » Phrase fausse tentante : « on régularise pour éviter l'overfitting ». C'est la conséquence, pas le mécanisme. Le mécanisme est aux pas 8 et 11 : existence et unicité.

Devant une loss ou une pénalité : de quel bruit, de quel prior est-elle la trace ? Et que fournit-elle que les données ne fournissaient pas ?
